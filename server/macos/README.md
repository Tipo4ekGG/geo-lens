# Полный geo-sleuth на Intel Mac, macOS Ventura 13+

Без аренды сервера и без Docker. Целевая машина: Intel, 8 GB RAM, macOS 13.7.8. Это конфигурация для проверки на вашем Mac, а не обещание, что все тяжёлые задачи поместятся в память.

## Установка
1. Скачайте исходники GitHub (Code → Download ZIP), распакуйте в обычную папку, не в Downloads с автоматической очисткой или iCloud Drive.
2. Откройте Terminal и выполните `bash `, перетащите туда `server/macos/install.sh` из распакованной папки и нажмите Enter. Либо откройте `Install on Intel Mac.command` через контекстное меню «Открыть».
3. Установщик проверит Ventura/Intel, скачает uv/Python 3.11, закреплённые библиотеки, Chromium и cloudflared. Может потребоваться несколько GB диска; держите хотя бы 8 GB свободными для окружений и весов. Он не меняет системный Python, не требует Docker или sudo.
4. Введите полный Base URL вашего API и действующий ключ в скрытом вводе. Ключ сохраняется только в `~/Library/Application Support/GeoLens/config.json`, права 0600. Конфигурацию не отправляйте в чат, GitHub или скриншотах.

## Запуск и связь с сайтом
1. Откройте `Start Geo Lens.command` (или `.venv-api/bin/python -m server.macos.launch` из папки проекта).
2. В Terminal появится HTTPS URL `*.trycloudflare.com`. В Cloudflare Worker `geo-lens-api` задайте `FULL_BACKEND_URL` = этот URL, тип Text.
3. Откройте `Copy Backend Token.command`: он копирует только серверный код в буфер обмена. Вставьте в Cloudflare Secret `FULL_BACKEND_TOKEN`. Это отдельный код, не ваш API-ключ и не прежний ACCESS_TOKEN сайта.
4. Если Cloudflare попросит, выполните Deploy. На GitHub-сайте в режиме «Полный geo-sleuth» запускайте фото. Модель должна поддерживать изображения и OpenAI tool calling. Старый быстрый режим — отдельная функция, он не подменяет полный при ошибках.
5. Окно Terminal должно оставаться открытым, Mac не должен спать. Ctrl+C останавливает запуск. URL Quick Tunnel меняется при каждом новом запуске; его нужно обновлять в Worker. Quick Tunnel — бесплатный временный тестовый доступ, не постоянный хостинг.

## Что делает этот вариант
Все 91 файл исходного скилла сохранены без изменений; 27 Python-файлов включают операторов и вспомогательные модули. Управляющая модель читает исходный SKILL.md, запускает intake, board и другие инструменты, просматривает картинки результатов и создаёт спецификации JSON для геометрии. Итоговый журнал и артефакты доступны на сайте. Если доска кандидатов не прошла проверку, координаты модели удаляются и вывод помечается низкой уверенностью. Проверка доски сама по себе не гарантирует правильное место.

Для Intel зафиксированы PyTorch 2.2.2 (последняя серия с официальными Intel Mac сборками), Transformers 4.40.2, NumPy 1.26.4 и ONNX Runtime 1.19.2. Вместо установки новых PEP723 окружений при каждом вложенном uv run используется маленький адаптер с заранее установленными зависимостями. Оригинальные скрипты не переписываются. OCR сначала использует Apple Vision; при недоступности bridge — RapidOCR. Модели CLIP/DINOv2 скачивают веса при первом использовании. Используется CPU, без предположений о наличии MPS на Intel.

## Ограничения памяти и доступа
Одно исследование за раз, 24 шага модели и до 40 минут по умолчанию. Каждый оператор — отдельный процесс; браузер, OCR и ML не держатся постоянно в одной памяти. Суммарный RSS оператора и дочерних процессов контролируется (по умолчанию 3500 MB); при превышении он завершается с явной отметкой незавершённой проверки. Это ограничение наблюдателя, не гарантия отсутствия системного memory pressure. Закройте тяжёлые приложения. Ограничивайте области сканирования; большие поиски могут не завершиться на 8 GB.

Нативные скрипты запускаются через macOS sandbox-exec с доступом к текущему заданию, кэшу и нужным библиотекам. Доступ к остальному домашнему каталогу и config.json не выдаётся. Ключи не передаются в окружение операторов. Это личный сервис с одним токеном, не публичная платформа. Если sandbox не работает, установщик останавливается, обхода защиты или автоматического запуска без sandbox нет. Полный доступ к диску в настройках macOS для этой установки не требуется.

Фото/артефакты сохраняются на Mac до очистки: старые завершённые задания удаляются при следующем обращении к API через 24 часа. Веса и браузер остаются в `~/Library/Caches/GeoLens`. Удаление проекта не удаляет отдельные настройки/кэш/задания автоматически.

## Диагностика
`.venv-api/bin/python -m server.macos.check` проверяет браузер, данные и sandbox, но не реальный API/поисковые сервисы/качество ML. Для изменения ключа выполните `.venv-api/bin/python -m server.macos.configure`. Не удаляйте сведения об ошибках ради «зелёного» статуса. Реальная работа на Intel Mac должна быть подтверждена установкой и первым заданием; Linux-тесты не являются такой проверкой.
